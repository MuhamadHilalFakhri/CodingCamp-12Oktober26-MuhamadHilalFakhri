# .kiro Configuration

Folder ini berisi konfigurasi Kiro untuk proyek Life Dashboard.

## 📁 Struktur

```
.kiro/
├── hooks/              # Automation hooks
│   └── file-save-notify.json
├── settings/           # MCP and other settings
├── steering/           # Project guidelines
│   ├── project-guide.md
│   └── css-patterns.md
└── README.md          # This file
```

## 📋 File Descriptions

### Hooks
- **file-save-notify.json** — Memberikan notifikasi setelah file disimpan dengan reminder untuk refresh browser

### Steering Files
- **project-guide.md** — Panduan lengkap struktur proyek, coding standards, dan workflow
- **css-patterns.md** — Pattern CSS yang digunakan (glassmorphism, animations, components)

## 🎯 Purpose

Folder `.kiro` membantu:
1. **Standardisasi** — Dokumentasi coding standards dan patterns
2. **Automation** — Hooks untuk workflow yang lebih efisien
3. **Guidance** — Steering files memberikan context kepada AI agent
4. **Consistency** — Memastikan semua perubahan mengikuti pola yang sama

## 📚 Untuk Instruktur/Reviewer

Folder ini menunjukkan:
- ✅ Pemahaman struktur proyek yang baik
- ✅ Dokumentasi yang komprehensif
- ✅ Best practices dalam development
- ✅ Penggunaan AI tooling yang proper
- ✅ Workflow automation awareness

## 🔧 Cara Menggunakan

Steering files akan otomatis digunakan oleh Kiro AI saat bekerja dengan proyek ini untuk:
- Memahami struktur dan pola yang digunakan
- Menjaga konsistensi coding style
- Memberikan saran yang sesuai dengan project guidelines
