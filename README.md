# Life Dashboard — Premium Edition ✨

Dashboard pribadi yang mewah dan profesional untuk mengelola waktu, tugas, dan link favorit Anda. Didesain dengan estetika modern, animasi halus, dan efek visual premium.

## 🎨 Fitur Premium

### ✨ Desain Visual Mewah
- **Glassmorphism Effects** — Backdrop blur dan transparansi untuk tampilan modern
- **Gradient Animations** — Animasi gradien yang bergerak pada elemen penting
- **Floating Ambient Lights** — Background ambient yang beranimasi lembut
- **Premium Shadows** — Multi-layer shadows untuk depth yang kaya
- **Shimmer Effects** — Efek berkilau pada logo dan progress bar

### 🎯 Fitur Utama
1. **⏱️ Focus Timer** — Pomodoro timer dengan:
   - Display waktu dengan gradient animasi
   - Progress bar dengan shimmer effect
   - Durasi yang dapat disesuaikan (1-180 menit)
   - Notifikasi audio saat selesai
   - Status badge yang interaktif

2. **✅ To-Do List** — Manajemen tugas dengan:
   - Checkbox animasi dengan checkmark bounce
   - Hover effects yang smooth
   - Edit dan hapus tugas
   - Indikator visual saat task selesai
   - Left border indicator saat hover

3. **🔗 Quick Links** — Link favorit dengan:
   - Avatar dengan gradient background
   - Rotating animation saat hover
   - Pill-shaped design modern
   - Remove button dengan rotate effect

## 🚀 Cara Menggunakan

1. **Buka `index.html`** di browser modern (Chrome, Firefox, Safari, Edge)
2. **Personalisasi:**
   - Masukkan nama Anda untuk greeting personal
   - Atur durasi focus timer sesuai kebutuhan
   - Tambahkan tugas-tugas Anda
   - Simpan link favorit Anda
3. **Toggle tema** dengan tombol di kanan atas
4. **Semua data tersimpan** di Local Storage browser Anda

## 📱 Responsive Breakpoints
- **Desktop** (> 960px) — 3 kolom layout
- **Tablet** (640px - 960px) — 2 kolom layout, timer full-width
- **Mobile** (< 640px) — 1 kolom layout stacked
